# Agentes  de OpenCode  para proyectos 

Este repositorio contiene los agentes de OpenCode que se utilizan en el proyecto [OpenCode](https://github.com/opencodeiii/openCodeIII).

## Cómo instalar

Para instalar los agentes de OpenCode en el proyecto [OpenCode](https://github.com/opencodeiii/openCodeIII) debes seguir los siguientes pasos:

1. Clonar el repositorio en el directorio `f:/proyectos_personales/.opencode/`
2. Abrir el archivo `f:/proyectos_personales/.opencode/config.json` y modificar la ruta de los agentes de OpenCode que se utilizan en el proyecto.
3.  Dar ordenes a los agentes de OpenCode para instalar los paquetes que se necesiten para el proyecto.
