## Skills opcionales

`nextjs-2026-best-practices`, `nivo-professional-charts`, `plotly-expert-charts`, `leaflet-maps-integration`, `recharts-charts` aplican solo si el usuario o una decisión de arquitectura adopta esas tecnologías.

## Convenciones

- Cada `SKILL.md` tiene frontmatter `name` igual al nombre de su carpeta.
- El contexto del proyecto prevalece sobre ejemplos genéricos.
- Las skills de workflow reutilizable deben evitar valores de un producto ajeno; mantener sus parámetros sincronizados con `context/`.
